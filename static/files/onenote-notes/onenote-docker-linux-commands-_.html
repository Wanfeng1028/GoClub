一、基础概念

  • 路径类型:
    • 绝对路径：从根目录 / 开始，例如 /etc/hosts
    • 相对路径：相对当前工作目录，例如 ./logs 或 ../tmp
  • 通配符与扩展:
    • 星号 * 匹配任意字符；问号 ? 匹配一个字符；方括号 [abc] 指定集合
    • 大括号扩展：file{1..3}.txt → file1.txt file2.txt file3.txt
  • 重定向与管道:

    • 覆盖输出，>> 追加输出，2> 重定向标准错误，| 用上一个命令的输出作为下一个命令输入

  • 权限位:
    • rwx 表示读、写、执行，分属用户/组/其他；数字表示法如 754 → 用户 rwx(7)、组 r-x(5)、其他 r--(4)

五、学习与使用建议

  • 将命令按任务组合，熟悉标准输入输出与管道。
  • 优先使用安全选项：例如 rm -i，find 配合 -print0 与 xargs -0。
  • 脚本中设置 set -euo pipefail，减少隐性错误。
  • 区分发行版包管理器与服务管理器（systemd vs SysV）。
