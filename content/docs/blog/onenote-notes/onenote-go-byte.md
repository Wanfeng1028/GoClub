<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">## 1. byte <span style="font-family: Microsoft YaHei,sans-serif">类型的基本概念</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">**byte <span style="font-family: Microsoft YaHei,sans-serif">是</span> uint8 <span style="font-family: Microsoft YaHei,sans-serif">的别名</span>**<span style="font-family: Microsoft YaHei,sans-serif">，表示一个</span> 8 <span style="font-family: Microsoft YaHei,sans-serif">位的无符号整数（</span>0-255<span style="font-family: Microsoft YaHei,sans-serif">）。</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```go</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">package main</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">import "fmt"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">func main() {</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // byte <span style="font-family: Microsoft YaHei,sans-serif">实际上是</span> uint8 <span style="font-family: Microsoft YaHei,sans-serif">的别名</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    var b byte = 65</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    var u uint8 = 65</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("byte: %d, uint8: %d\n", b, u) // <span style="font-family: Microsoft YaHei,sans-serif">输出</span>: byte: 65, uint8: 65</p></div>

<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">}</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```</p></div>

<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">## 2. byte <span style="font-family: Microsoft YaHei,sans-serif">的字面值表示</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```go</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">package main</p></div>

<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">查找</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    index := bytes.Index(data, []byte("ll"))</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("'ll' <span style="font-family: Microsoft YaHei,sans-serif">在位置</span>: %d\n", index) // 2</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">}</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">## 7. byte <span style="font-family: Microsoft YaHei,sans-serif">与</span> rune <span style="font-family: Microsoft YaHei,sans-serif">的区别</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```go</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">package main</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">import "fmt"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">func main() {</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    text := "Hello <span style="font-family: Microsoft YaHei,sans-serif">世界</span>"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Println("<span style="font-family: Microsoft YaHei,sans-serif">字符串</span>:", text)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Println("<span style="font-family: Microsoft YaHei,sans-serif">长度</span>:", len(text)) // byte <span style="font-family: Microsoft YaHei,sans-serif">长度</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">按</span> byte <span style="font-family: Microsoft YaHei,sans-serif">遍历</span> (UTF-8 <span style="font-family: Microsoft YaHei,sans-serif">编码</span>)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Println("\n<span style="font-family: Microsoft YaHei,sans-serif">按</span> byte <span style="font-family: Microsoft YaHei,sans-serif">遍历</span>:")</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    for i := 0; i < len(text); i++ {</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">        fmt.Printf("byte[%d]: %c (0x%02x)\n", i, text[i], text[i])</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    }</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">按</span> rune <span style="font-family: Microsoft YaHei,sans-serif">遍历</span> (Unicode <span style="font-family: Microsoft YaHei,sans-serif">字符</span>)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Println("\n<span style="font-family: Microsoft YaHei,sans-serif">按</span> rune <span style="font-family: Microsoft YaHei,sans-serif">遍历</span>:")</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    for i, r := range text {</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">        fmt.Printf("rune[%d]: %c (U+%04x)\n", i, r, r)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    }</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">}</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">## 8. <span style="font-family: Microsoft YaHei,sans-serif">常用转换操作</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```go</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">package main</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">import (</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    "fmt"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    "strconv"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">func main() {</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">数字与</span> byte <span style="font-family: Microsoft YaHei,sans-serif">的转换</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    num := 65</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    b := byte(num)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("<span style="font-family: Microsoft YaHei,sans-serif">数字</span> %d -> byte: %c\n", num, b)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">字符串与</span> byte</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    str := "A"</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    byteFromStr := str[0]</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("<span style="font-family: Microsoft YaHei,sans-serif">字符串</span> %s -> byte: %d\n", str, byteFromStr)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // byte <span style="font-family: Microsoft YaHei,sans-serif">与十六进制字符串</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    hexStr := fmt.Sprintf("%02x", b)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("byte %d -> <span style="font-family: Microsoft YaHei,sans-serif">十六进制</span>: %s\n", b, hexStr)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    </p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    // <span style="font-family: Microsoft YaHei,sans-serif">解析十六进制字符串为</span> byte</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    parsed, _ := strconv.ParseUint("41", 16, 8)</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">    fmt.Printf("<span style="font-family: Microsoft YaHei,sans-serif">十六进制</span> 41 -> byte: %c\n", byte(parsed))</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">}</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">```</p></div>

<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">## <span style="font-family: Microsoft YaHei,sans-serif">总结</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">&nbsp;</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">**byte <span style="font-family: Microsoft YaHei,sans-serif">类型的特点：</span>**</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">- <span style="font-family: Microsoft YaHei,sans-serif">是</span> `uint8` <span style="font-family: Microsoft YaHei,sans-serif">的别名，范围</span> 0-255</p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">- <span style="font-family: Microsoft YaHei,sans-serif">用于表示原始二进制数据和</span> ASCII <span style="font-family: Microsoft YaHei,sans-serif">字符</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">- <span style="font-family: Microsoft YaHei,sans-serif">适合处理文件、网络数据等底层操作</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">- <span style="font-family: Microsoft YaHei,sans-serif">字符串在底层就是</span> `byte` <span style="font-family: Microsoft YaHei,sans-serif">切片</span></p></div>
<div class="outline-element" style="margin-left: 0px"><p style="font-family: Calibri,sans-serif; font-size: 11pt">- <span style="font-family: Microsoft YaHei,sans-serif">与</span> `rune`<span style="font-family: Microsoft YaHei,sans-serif">（</span>int32<span style="font-family: Microsoft YaHei,sans-serif">）不同，</span>`byte` <span style="font-family: Microsoft YaHei,sans-serif">只能处理</span> ASCII<span style="font-family: Microsoft YaHei,sans-serif">，不能处理多字节</span> Unicode</p></div>
